# Metodologia (método da casa)


Todo experimento no repo segue este template (`docs/metodologia/HIPOTESE.md`):

```markdown
# Hipótese H-YYYYMMDD-N
## Artefato
- origem (próprio / licenciado / CTF / lab)
- hash SHA-256
## Hipótese
- o que acho que está acontecendo
## Experimento
- comando / workflow
- ferramentas e versões
## Resultado
- métrica (nome, valor, limiar de sucesso)
## Reconstrução
- o que foi recriado (parser, stem, receita, patch de lab)
## Conclusão
- confirmada / refutada / inconclusiva
## Próximo passo
```

Regras:
- Sem artefato sem hash.
- Sem conclusão sem métrica.
- Sem commit sem link para a hipótese.
- Trabalho só em material legal.
