# Referências (só grátis/open)

## 4. Cursos, livros e plataformas (só grátis / open)

### 4.1 Cursos (ordem sugerida)

1. **OpenSecurityTraining2** — https://ost2.fyi / https://p.ost2.fyi  
   Arch 1001 → Dbg1102 (Ghidra) → RE 2001 (static C) → RE 2102 (Ghidra interm.) → RE 3011 (C++) → RE 3201 (symbolic) → RE 5001 (UEFI).
2. **pwn.college** — https://pwn.college (CSE 365 Spring 2026, Módulo 5: Reverse Engineering / cIMG).
3. **Nightmare** — https://github.com/guyinatuxedo/nightmare (RE + pwn com writeups, 90+ challenges, tools OSS).
4. **FLARE Learning Hub** — https://github.com/mandiant/flare-learning-hub (Malware Crash Course, Go RE Ref, TTD).
5. **How2Rev** — https://how2rev.github.io (trilha CTF-style, obfuscation).
6. **LearnReverseEngineering.com** — C→asm prático x64.
7. **Epoch Zero REMA** — https://learn.epochzero.net/learn/rema (malware + RE, acesso aberto).
8. **FMP Notebooks** (MIR) — https://www.audiolabs-erlangen.de/FMP (Meinard Müller).
9. **Intro to Differentiable DSP** — https://intro2ddsp.github.io (ISMIR 2023).
10. **OST1 Reverse Engineering Malware** (arquivo) — https://www.opensecuritytraining.info/ReverseEngineeringMalware.html.

### 4.2 Livros (edição gratuita / PDF oficial)

- *Reverse Engineering for Beginners* (Dennis Yurichev) — https://beginners.re (grátis).
- *Practical Binary Analysis* (Dennis Andriesse) — checar PDF oficial No Starch / autor; senão, biblioteca.
- *Fundamentals of Music Processing* (Müller) — notebooks FMP cobrem a prática; livro é pago, notebooks são grátis.
- *Practical Malware Analysis* (Sikorski/Honig) — livro pago; labs públicos: https://github.com/RPISEC/Malware.
- *The Ghidra Book* — pago; cobrir com OST2 Dbg1102 + docs oficiais Ghidra.

### 4.4 Ferramentas núcleo (open source)

**Binários:** Ghidra (Apache-2.0), rizin/Cutter (LGPL), angr (BSD), Frida (wxWindows/LGPL-like), GDB+pwndbg, binwalk, yara.  
**Áudio:** librosa, pyloudnorm, beat_this, allin1, Demucs, pedalboard, dasp-pytorch, grafx, basic-pitch, audioseal, chromaprint.  
**Vídeo:** ffmpeg/ffprobe, PySceneDetect, TransNetV2, colour-science, OpenCV, EasyOCR.  
**Formatos:** Kaitai Struct, ImHex, MediaInfo, GPAC.  
**Modelos:** Netron, safetensors, nnsight, torchinfo.  
**Protocolos:** Wireshark/tshark, mitmproxy.

Descartar: IDA Pro pago, Binary Ninja pago (existe free limited — preferir Ghidra), DeepAFx-ST e Diff-MST (licença não comercial).
