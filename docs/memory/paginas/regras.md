# Regras do E.R. (fixas)

- Custo zero e open source sempre.
- Sem API, sem token, sem cadastro. Nenhuma ferramenta pode pedir chave no meio da instalação.
- Roda só em CPU no GitHub Actions (runner gratuito, repositório público).
- Nunca commitar binários de terceiros: tudo é baixado da fonte oficial na hora e fica em cache.
- Só trabalho legal: sem quebrar DRM nem contornar proteção técnica.
- Foco: engenharia reversa digital (áudio, vídeo, apps), com cobertura de formatos, protocolos, binários e modelos.
- Documentação em português do Brasil.
